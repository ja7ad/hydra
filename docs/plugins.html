Install in Hydra opens the desktop app to review permissions before installation. Choose the package for your operating system and processor. If your browser cannot open Hydra, download the package and open it with Hydra, or add it in Options → Extensions & Plugins → Plugins.

Keep your plugins up to date

Hydra includes this catalog by default in the GUI and CLI. Choose “Check plugin updates” in Options → Extensions & Plugins → Plugins, or run hydra plugin update to see available versions.

https://hydra.javad.dev/plugins.json

The default catalog stays available when you add your own mirrors, and takes precedence for duplicate plugin IDs. Catalog entries can pin a package checksum and publisher signing key. Updates require your approval.
